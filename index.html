      Set Up Reminders & Notes

      The dashboard can't read Apple's apps by itself, so a shortcut collects your reminders and notes and hands them over. You build it once in the Shortcuts app.

      1. Pick your notes

      In Notes, add #home to the first line of each note you want on the dashboard, for example "Wi-Fi password #home". The tag is hidden on the dashboard.

      2. Build the shortcut

      1. In Shortcuts, tap Create Shortcut. Open its settings and name it Dashboard Sync.
      2. Add Find Reminders. Tap Add Filter and set it to Is Completed is false. (No Find Reminders? Use Get Upcoming Reminders.)
      3. Add Combine Text set to New Lines, then Set Variable named Rem.
      4. Add Find Notes. Tap Add Filter and set it to Name contains #home.
      5. Add Repeat with Each. Inside it, add Text: type @@NOTE, start a new line, then insert the Repeat Item variable.
      6. After End Repeat, add Combine Text (New Lines), then Set Variable named Notes.
      7. Add Text with three lines: @@REMINDERS, then the Rem variable, then the Notes variable.
      8. Add URL Encode.
      9. Add Text: followed straight away by the URL Encoded Text variable, with no space.
      10. Add Open URLs.

      3. Use it

      Open the dashboard in Safari, not from the Home Screen icon, and tap ↻ on the Reminders or Notes tile. The iPad switches to Shortcuts for a moment, then comes back with your items.

      Ticking a synced reminder on the dashboard only hides it here. It stays open in the Reminders app. Each sync may open a new Safari tab, so close old ones now and then.
